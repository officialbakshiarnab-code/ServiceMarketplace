## ?? Requirements Status

### Manual Logout Audit
- ? Authenticated API endpoint: `POST /api/auth/logout`
- ? Read UserId, Role, SessionId from JWT
- ? Call AuditLogService
- ? Insert new AuditLogs row: EventType = "Logout", TimestampUtc = now
- ? UI calls API BEFORE clearing tokens
- ? Never update existing rows (append-only)

**Result**: ? Manual logout always creates an AuditLogs record

### Session Expiry Audit (10 Minutes)
- ? Detect token expiry in TokenAuthenticationStateProvider
- ? Call API endpoint: `POST /api/auth/token-expired`
- ? Validate expired token safely (no [Authorize])
- ? Insert AuditLogs row: EventType = "SessionExpired", TimestampUtc = now
- ? Exactly one audit row per expiry (duplicate prevention)
- ? No UI-side DB writes (all server-side)

**Result**: ? Session expiry creates a clean audit trail

    GROUP BY SessionId
    HAVING COUNT(*) > 2

SELECT 
    AVG(DATEDIFF(MINUTE, Login.TimestampUtc, Logout.TimestampUtc)) as AvgMinutes

    (SELECT SessionId, TimestampUtc FROM AuditLogs WHERE EventType = 'Login') Login
INNER JOIN

## ?? Expected Database Schema

```sql
CREATE TABLE AuditLogs (
    Id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),
    UserId NVARCHAR(450) NOT NULL,
    Role NVARCHAR(50) NULL,
    EventType NVARCHAR(50) NOT NULL,  -- 'Login', 'Logout', 'SessionExpired'
    TimestampUtc DATETIME2 NOT NULL,
    SessionId NVARCHAR(100) NULL,
    IpAddress NVARCHAR(45) NULL,
    UserAgent NVARCHAR(500) NULL
);

-- Indexes for performance
CREATE INDEX IX_AuditLogs_UserId 
    ON AuditLogs(UserId);

CREATE INDEX IX_AuditLogs_SessionId 
    ON AuditLogs(SessionId);

CREATE INDEX IX_AuditLogs_TimestampUtc 
    ON AuditLogs(TimestampUtc DESC);

-- Composite index for duplicate prevention
CREATE INDEX IX_AuditLogs_SessionId_EventType 
    ON AuditLogs(SessionId, EventType);
```
