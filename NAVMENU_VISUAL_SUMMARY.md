## Key Behaviors

### ? Authentication Check
```
Blazor Framework
?? AuthenticationStateProvider
   ?? Calls GetAuthenticationStateAsync()
      ?? Returns ClaimsPrincipal
         ?? Identity.IsAuthenticated (bool)
         ?? FindAll(ClaimTypes.Role) (IList<Claim>)
         ?? Other claims (email, name, etc)
```

### ? NavLink Active State
```
<NavLink href="/user/dashboard" class="nav-link">

```


## Testing Scenarios

```
Scenario 1: First Time Visitor (No Auth)
Step 1: Visit application
Step 2: AuthorizeView checks token ? Not found
Step 3: NotAuthorized fragment renders
Result: See "Login" and "Register" only ?

Scenario 2: Login Flow
Step 1: User logs in
Step 2: JWT stored in LocalStorage
Step 3: AuthStateProvider notified
Step 4: AuthorizeView re-evaluates
Step 5: Authorized fragment renders
Result: See authenticated navigation ?

Scenario 3: User with User Role
Step 1: JWT contains role="User"
Step 2: RoleNavLinks checks roles
Step 3: First AuthorizeView (Roles="User") matches
Step 4: User-specific links shown
Result: "Create Request", "My Requests" visible ?
Result: "Available Requests", "My Bids" NOT visible ?

Scenario 4: User with Provider Role
Step 1: JWT contains role="ServiceProvider"
Step 2: RoleNavLinks checks roles
Step 3: Second AuthorizeView (Roles="Provider") matches
Step 4: Provider-specific links shown
Result: "Available Requests", "My Bids" visible ?
Result: "Create Request", "My Requests" NOT visible ?

Scenario 5: Logout
Step 1: User clicks "Sign Out"
Step 2: LogoutButton calls SafeLogoutService
Step 3: JWT token removed from LocalStorage
Step 4: AuthStateProvider.NotifyAuthenticationStateChanged()
Step 5: AuthorizeView re-evaluates ? NotAuthorized
Step 6: Navigates to /login
Result: See login/register again ?
Result: All authenticated nav gone ?
```
