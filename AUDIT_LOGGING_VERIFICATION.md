## ? Data Consistency

### AuditLog Entity Fields
```csharp
public class AuditLog
{
    public Guid Id { get; set; }
    public string UserId { get; set; }         // ? Required
    public string? Role { get; set; }          // ? Captured
    public string EventType { get; set; }      // ? Login|Logout|SessionExpired
    public DateTime TimestampUtc { get; set; } // ? Always UTC
    public string? SessionId { get; set; }     // ? From JWT jti
    public string? IpAddress { get; set; }     // ? Client IP
    public string? UserAgent { get; set; }     // ? HTTP header
}
```

### Timestamp Consistency
- ? All timestamps created in `AuditLogService.RecordEventAsync()`
- ? Always uses `DateTime.UtcNow`
- ? No timezone conversion needed

### Duplicate Prevention
- ? `LogSessionExpiredAsync()` checks existing SessionExpired events
- ? Returns `bool` to indicate if event was logged
- ? Uses SessionId for duplicate detection

## ? Testability

### Unit Test: AuditLogService
```csharp
[Fact]
public async Task LogLoginAsync_CreatesAuditLogWithCorrectData()
{
    // Arrange
    var mockContext = CreateMockDbContext();
    var mockLogger = CreateMockLogger();
    var service = new AuditLogService(mockContext, mockLogger);
    
    // Act
    await service.LogLoginAsync("user123", "User", "session456", "192.168.1.1", "Mozilla/5.0");
    
    // Assert
    var log = mockContext.AuditLogs.Single();
    Assert.Equal("user123", log.UserId);
    Assert.Equal("User", log.Role);
    Assert.Equal("Login", log.EventType);
    Assert.Equal("session456", log.SessionId);
}
```

### Unit Test: AuthService
```csharp
[Fact]
public async Task LoginAsync_CallsAuditLogService()
{
    // Arrange
    var mockAuditService = new Mock<IAuditLogService>();
    var authService = new AuthService(..., mockAuditService.Object, ...);
    
    // Act
    await authService.LoginAsync("user@test.com", "password", "agent", "ip");
    
    // Assert
    mockAuditService.Verify(
        x => x.LogLoginAsync(It.IsAny<string>(), It.IsAny<string>(), 
                            It.IsAny<string>(), "ip", "agent"),
        Times.Once
    );
}
```

**Result:** ? Easy to mock IAuditLogService in tests
